# FATE-Amazonia2.0 Forest fire emissions model

This repository supports the scientific publication *"Unveiling the Hidden Greenhouse Gases Footprint of Amazonian Forest Fires"*, submitted to *Nature Communications* in 2025 and led by researchers from INPE and IPAM.

The repository contains:

- Google Earth Engine (JavaScript) scripts used for spatial modeling and large-scale geospatial data processing;
- R workflows for greenhouse gas emissions calculations, and figure generation;

Part of the emissions outputs generated by the FATE model are also incorporated into the SEEG Fire Platform.

## Code Ocean Reproducibility (codeocean branch)

The `codeocean` branch contains additional files enabling fully reproducible execution on the [Code Ocean](https://codeocean.com) platform:

| File | Purpose |
|------|---------|
| `run` | Bash driver script that executes the full analysis pipeline |
| `code/R/master.R` | Master R script that sources all analysis scripts in order |
| `environment/Dockerfile` | Docker container definition (R 4.1.2 + required packages) |
| `metadata/metadata.yml` | Capsule metadata (title, authors, tags, research field) |

### R Package Dependencies

`data.table`, `openxlsx`, `dplyr`, `reshape2`, `tidyr`, `ggplot2`, `scales`, `egg`, `svglite`, `plyr`, `viridis`

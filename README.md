# FATE-SEEG Forest fire emissions model

This repository supports the scientific publication *“Unveiling the Hidden Greenhouse Gases Footprint of Amazonian Forest Fires”*, submitted to *Nature Communications* in 2025 and led by researchers from INPE and IPAM.

The repository contains:

- Google Earth Engine (JavaScript) scripts used for spatial modeling and large-scale geospatial data processing;
- R workflows for greenhouse gas emissions calculations, and figure generation;

Part of the emissions outputs generated by the FATE model are also incorporated into the SEEG Fire Platform.

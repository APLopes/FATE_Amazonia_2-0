# R codes

R analysis workflows for processing Google Earth Engine model outputs and field
inventory data, generating the figures and source data tables for the FATE-SEEG
manuscript. The scripts are orchestrated by `master.R`, which sources them in the
correct order.

## Scripts

| Script | Description | Figure / Output |
|--------|-------------|-----------------|
| `master.R` | Master orchestration script. Sources all analysis scripts in order: Fig 1 -> Fig 2 -> Fig 3. | --- |
| `1.Script_Deforestation_analyses_Fig1.R` | Processes GEE deforestation outputs: burned and deforested forest area per year, burn frequency, time-since-fire. Generates boxes b, c, d. Box a (map) is pre-rendered from GEE and assembled manually in Inkscape. | Figure 1 (boxes b-d) + source data tables (XLSX) |
| `2.Script_AGB_change_analyses_Fig2.R` | Processes field inventory data from burned forest plots. Fits nonlinear AGB change model as a function of time since fire. | Figure 2 |
| `3.Script_GEE_model_output_Fig3.R` | Processes FATE model outputs (CO2, CH4, CO, N2O, NOX). Aggregates combustion, mortality, and decomposition emissions. | Figure 3 + source data tables (XLSX) |

## Outputs

### Figure 1 notes

Figure 1 is composed of four boxes. Box a (map of accumulated burned area in 2020) is generated by Google Earth Engine (`Paper_fig1_map.js`) and assembled manually in Inkscape. Boxes b, c, d are generated by Script 1.

## R Package Dependencies

`data.table`, `openxlsx`, `dplyr`, `reshape2`, `tidyr`, `ggplot2`, `scales`,
`egg`, `svglite`, `plyr`, `viridis`

## Execution

On Code Ocean, the capsule's `run` script invokes:

```bash
Rscript R/master.R "$@"
```

Locally (with the working directory set to the repository root):

```r
source("code/R/master.R")
```
